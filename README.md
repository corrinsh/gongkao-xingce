# 行测真题库 · 广东考生版

2016—2026 国考 + 广东省考 + 广州/深圳 行测真题，按考点刷题、整卷模考、错题本、弱项诊断。
纯静态站点，无后端；做题记录只存在浏览器 localStorage。

## 数据来源
题目来自开源仓库 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)（全库 515 套 / 58,890 题）。
本页只打包广东考生相关范围：59 套 / 6592 题。答案与解析来自第三方题库，回忆版可能有误。
